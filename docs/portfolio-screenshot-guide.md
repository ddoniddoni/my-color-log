# 포트폴리오 화면 캡처 가이드

README에는 실제 앱 화면만 사용한다. 테스트 계정의 이메일, 초대 코드, 푸시 토큰, 사진 EXIF 정보와 실제 지인 사진은 노출하지 않는다.

## 권장 환경

- iPhone portrait, 기준 폭 390pt
- 상태 바가 자연스럽게 보이는 전체 화면 캡처
- 샘플 닉네임·방 이름·사진만 사용
- 같은 오늘의 컬러를 사용해 화면 사이의 맥락을 유지

`docs/images/portfolio/`에 아래 파일명으로 저장한다.

| 선택: `06-camera-review.png` | 촬영 후 미리보기·캡션 | 기록을 남기는 실제 행동 |

## README 반영 순서

1. 위 경로에 PNG 6장을 추가한다.
2. 이미지에 실명·이메일·초대 코드·실제 지인 사진이 없는지 검토한다.
3. README의 `화면 캡처 추가하기` 문단을 화면 갤러리로 교체한다.
4. 모바일과 GitHub 다크 모드 모두에서 이미지가 읽히는지 확인한다.

## 화면 녹화 선택 사항

30~60초짜리 세로 영상 하나가 있으면 좋다. 온보딩 → 룰렛 → 촬영 → 오늘 기록 → 다이어리 → 친구방 순으로 보여 주며, 실제 사용자의 사진·이메일·초대 코드는 사용하지 않는다.
