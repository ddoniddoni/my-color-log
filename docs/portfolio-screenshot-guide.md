### 추가하면 좋은 화면

- [ ] 오늘: 샘플 사진으로 채운 9칸
- [ ] 색 강조: 같은 사진의 보기 설정 OFF/ON 및 닫은 뒤 9칸 반영
- [ ] 친구방: 초대 코드·계정 정보가 보이지 않는 샘플 방
- [ ] 다이어리: 하루 콜라주 내보내기
- [ ] 내 정보: 계정 정보를 노출하지 않는 설정 화면

## 권장 환경

- iPhone portrait, 기준 폭 390pt
- 상태 바가 자연스럽게 보이는 전체 화면 캡처
- 샘플 닉네임·방 이름·사진만 사용
- 같은 오늘의 컬러를 사용해 화면 사이의 맥락을 유지

## README 반영 순서

1. 위 경로의 기존 이미지를 최신 캡처로 교체하고, 필요한 추가 화면을 저장한다.
2. 이미지에 실명·이메일·초대 코드·실제 지인 사진이 없는지 검토한다.
3. README의 `화면 둘러보기` 갤러리와 설명·대체 텍스트를 갱신한다. 실제 최신 캡처로 교체한 뒤 이전 개발 버전 안내를 수정한다.
4. 모바일과 GitHub 다크 모드 모두에서 이미지가 읽히는지 확인한다.

## 화면 녹화 선택 사항

30~60초짜리 세로 영상 하나가 있으면 좋다. 온보딩 → 룰렛 → 촬영 → 오늘 기록 → 다이어리 → 친구방 순으로 보여 주며, 실제 사용자의 사진·이메일·초대 코드는 사용하지 않는다.
