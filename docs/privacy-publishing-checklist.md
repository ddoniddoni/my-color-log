# 개인정보 페이지 배포 체크리스트

## 공개 전에 채울 값

- [ ] 운영자 법적 이름 또는 사업자명
- [ ] 개인정보 문의 이메일과 고객지원 주소
- [ ] 개인정보 보호 책임자 또는 담당 부서
- [ ] 개인정보 처리방침 시행일
- [ ] Supabase 프로젝트 리전과 백업 보관 기간
- [ ] Expo Push Notification Service의 국외 이전 정보
- [ ] 외부 계정 삭제 요청 양식 또는 이메일 처리 절차와 처리 기한
- [ ] `privacy`, `delete-account`의 실제 공개 URL
- [ ] 회원가입 화면의 만 14세 미만 차단과 처리방침의 아동 개인정보 문구가 일치하는지 확인
- [ ] 처리방침이 최신 앱 동작·SDK·스토어 데이터 선언과 일치하는지 법률 검토

## 페이지 구성

```text
https://[도메인]/privacy
https://[도메인]/delete-account
```

두 페이지는 로그인, 지역 제한, 앱 설치 또는 PDF 다운로드 없이 열려야 합니다. 공개된 페이지를 수정할 때마다 처리방침의 시행일과 최종 업데이트일도 갱신합니다.

## 앱과 스토어 연결

- [ ] 앱 설정에 `개인정보 처리방침` 링크를 추가한다.
- [ ] 앱 내 `계정 삭제` 기능이 실제로 작동하는지 확인한다.
- [ ] App Store Connect에 Privacy Policy URL과 실제 데이터 처리에 맞는 App Privacy 정보를 입력한다.
- [ ] Google Play Console에 Privacy Policy URL, Data safety, Data deletion URL을 입력한다.
- [ ] 심사 계정이 필요하면 심사자가 계정 삭제와 사진 공유 흐름을 재현할 수 있게 준비한다.

## 운영 절차

외부 삭제 요청을 이메일이나 폼으로 받을 경우, 요청자의 이메일 소유를 확인한 뒤 처리합니다. 요청·확인·처리·응답 일시와 최소한의 처리 근거를 내부적으로 기록하되, 사진·캡션·인증 토큰은 기록하지 않습니다.

분석, 광고, 새 로그인 방식, 새 권한 또는 새 외부 SDK를 추가할 때는 처리방침과 두 스토어의 데이터 고지를 함께 검토·갱신합니다.
