# 촬영 가이드와 저장 사진의 구도 일치

관련 요구사항: `PRD.md`의 FR-PHOTO-001, FR-PHOTO-002.

## 원인과 수정

기존 촬영 화면은 전체 화면에 카메라 영상을 채우고 그 위에 작은 정사각형 가이드를 표시했다. 가이드는 상단·하단 조작 영역 때문에 화면 중앙보다 위에 위치하지만, 저장 시에는 가이드와 무관하게 사진 중앙의 가장 큰 정사각형을 잘랐다. 따라서 가이드 밖의 피사체까지 저장되거나 구도가 아래로 이동했다.

이제 카메라, 가이드 컨테이너, 가이드의 실제 `onLayout` 좌표를 측정한다. 가이드 테두리 안쪽을 카메라 좌표로 변환하고, 촬영 결과 파일의 실제 크기에 맞춰 같은 영역을 자른 뒤 기존 리사이즈·로컬 저장·업로드 큐 처리를 진행한다. 카메라 준비와 유효한 좌표 측정이 모두 끝나야 촬영 버튼을 활성화한다. 촬영 중 레이아웃이 바뀌어도 해당 촬영은 셔터를 누를 때의 가이드 좌표를 사용한다.

## 좌표 변환

`cameraFraming.ts`에서 다음을 처리한다.

1. 가이드 컨테이너와 가이드의 상대 좌표를 합치고 카메라 위치를 뺀다.
2. 가이드의 2dp 테두리를 제외한다.
3. 화면을 채우는 배율 `max(미리보기 너비 / 사진 너비, 미리보기 높이 / 사진 높이)`를 계산한다.
4. 화면을 채우면서 보이지 않게 된 사진 양쪽 영역을 보정해 가이드를 사진 좌표로 역변환한다.
5. 사진 픽셀 단위로 반올림하고 파일 경계를 넘지 않는 정사각형을 만든다.

예를 들어 미리보기 400×800, 가이드 안쪽 `(24, 187, 352, 352)`, 촬영 파일 4000×8000이면 기존 자르기는 `(0, 2000, 4000, 4000)`이었다. 수정 후에는 `(240, 1870, 3520, 3520)`을 저장한다. 화면 너비 비율이나 기기 모델별 상수를 자르기 기준으로 사용하지 않는다.

## Expo Camera와의 계약

- 현재 설치 버전은 `expo-camera` 57.0.6이다.
- `ratio`를 지정하지 않는 화면 채움 방식과 `skipProcessing: false`를 유지한다.
- iOS는 이미 미리보기 비율로 잘린 파일을 반환할 수 있고, Android는 방향이 보정된 센서 이미지 전체를 반환할 수 있다. 플랫폼을 추측하는 대신 반환된 파일 크기를 사용한다.
- `ratio`, `pictureSize`, 방향 처리 또는 카메라 미리보기의 배치 방식을 바꿀 때는 이 변환과 실제 기기의 구도를 함께 재확인한다.

확인한 구현은 `expo-camera/ios/Current/CameraView.swift`, `CameraPhotoCapture.swift`, `expo-camera/android/src/main/java/expo/modules/camera/ExpoCameraView.kt` 및 `tasks/ResolveTakenPicture.kt`다. API 계약은 [Expo SDK 57 Camera 공식 문서](https://docs.expo.dev/versions/v57.0.0/sdk/camera/)를 참고한다.

갤러리 가져오기는 가이드 좌표 없이 기존 중앙 정사각형 자르기를 사용한다. 기존 저장 사진을 다시 자르지 않는다. DB, 사진 소유권, 큐 스키마, 의존성 및 네이티브 설정 변경은 없다.

## 자동 검증 결과

- 수정 전 저장소 회귀 테스트에서 잘못된 자르기와 잘못된 가이드 허용을 재현했다.
- 카메라 관련 테스트: 12개 스위트, 85개 테스트 통과.
- 전체 `npm run check`: 타입 검사·린트, 앱 테스트 88개 스위트/428개 테스트, 색 강조 평가 도구 테스트 10개, 설정 테스트 21개 통과.
- 새 테스트 25개는 실제 가이드 좌표 전달, 중첩 좌표·테두리, 화면 밖 센서 영역, 태블릿 최대 너비, 소수점 좌표, 파일 경계, 촬영 준비 및 촬영 중 좌표 변경을 검증한다.

## 마지막 실기기 QA

이번 수정에서 네이티브 빌드나 기기 설치는 실행하지 않았다. 자동 검증은 좌표 변환과 저장 경로를 검증하며, 실제 카메라 영상의 구도 일치까지 확인한 것은 아니다. 마지막 통합 빌드 후 iPhone과 Android에서 다음을 확인한다.

- 가이드 네 변 바로 안쪽과 바깥쪽에 구분 가능한 물체를 두고 촬영한다. 촬영 결과에서 안쪽 물체가 유지되고 바깥쪽 물체가 제외되는지 확인한다.
- 가이드 중심과 화면 중심이 다른 상태에서도 위·아래 구도가 이동하지 않는지 확인한다.
- 가까운 물체와 먼 물체를 각각 촬영해 렌즈 전환·안정화 등 기기별 미리보기 차이를 확인한다.
- 촬영 직후 미리보기와 저장 후 다시 연 사진의 구도가 같은지 확인한다. 오늘의 색 강조 켜기·끄기도 확인한다.
- 작은 화면과 큰 화면에서 가이드가 화면 안에 들어오고, 세로 방향 유지 및 카메라 재진입 후에도 동일하게 동작하는지 확인한다.
