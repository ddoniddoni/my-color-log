# Color Log

> 오늘 스쳐 간 한 가지 색을 사진으로 남기는, 나와 친구들의 컬러 다이어리.

매일 하나의 색이 오늘의 작은 미션으로 찾아와요. 하늘빛, 컵의 초록, 퇴근길의 주황처럼 평소라면 지나쳤을 장면을 한 장씩 담아 보세요. 사진은 내 다이어리에 차곡차곡 쌓이고, 친구와 함께라면 같은 색으로 보낸 서로 다른 하루도 만날 수 있어요.

## 오늘의 색을 발견하는 방법

1. **오늘의 컬러 룰렛**을 돌려 오늘의 색을 만나요.
2. 하루 동안 발견한 장면을 **최대 9장**까지 기록해요.
3. 사진 한 장만으로도 충분한 오늘의 기록이 되고, 6장과 9장을 채우면 오늘이 조금 더 풍성해져요.
4. 달력과 3×3 기록판에서 시간이 쌓인 나만의 색을 다시 꺼내 봐요.

## 혼자여도, 함께여도

Color Log는 친구가 없어도 완전한 개인 다이어리예요. 사진은 언제나 먼저 내 기록으로 저장돼요.

친구와 함께하고 싶을 땐 비공개 친구방을 만들거나 초대 코드로 참여할 수 있어요. 같은 방의 멤버는 매일 같은 컬러 미션을 받고, 각자가 찍은 사진은 멤버별 보드에서 따로 볼 수 있어요. 한 사람이 참여할 수 있는 방은 최대 3개이며, 오늘 찍은 내 사진은 참여 중인 모든 방에 함께 공유돼요.

방에서 사진을 보더라도 원본은 각자의 다이어리에 남아요. 방을 나가도 내가 남긴 사진과 기록은 사라지지 않아요.

## 이런 순간을 위해 만들었어요

- 긴 글 없이도 오늘을 남기고 싶은 날
- 매일 무엇을 기록할지 가벼운 계기가 필요한 날
- 연인, 가족, 가까운 친구와 서로의 하루를 부담 없이 보고 싶은 날
- 공개 SNS가 아닌, 초대한 사람끼리만 보는 작은 공간이 필요한 날

## 주요 기능

- 이메일·비밀번호 회원가입 및 로그인
- 매일 바뀌는 서버 기반 오늘의 컬러 미션과 룰렛 공개
- 앱 카메라 촬영, 재촬영, 간단한 메모와 사진 순서 변경
- 하루 최대 9장의 개인 사진 기록
- 촬영 직후 기기에 보관하고, 연결되면 안전하게 업로드하는 동기화 흐름
- 월별 컬러 달력과 날짜별 3×3 다이어리
- 비공개 친구방 생성·참여, 6자리 초대 코드
- 친구방별 멤버 사진 보드와 지난 기록
- 닉네임 수정, 로그아웃, 계정 삭제

## 내 사진은 내 기록으로

사진은 공개 피드에 올라가지 않아요. 비공개 저장소와 접근 권한 정책을 통해, 내가 참여한 친구방의 멤버만 공유된 사진을 볼 수 있어요. 친구방은 사진을 복사해 보관하지 않고 내 개인 기록을 안전하게 연결해 보여줘요.
